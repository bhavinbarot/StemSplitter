Analysis Thresholds

Fine-tune detection sensitivity

BPM Change Threshold
Minimum BPM difference to report a tempo change segment (default 7.0)
Note Energy Threshold
Minimum HPCP energy (0–1) for a frame to receive a swara label (default 0.12)
Note Minimum Duration (s)
Shortest note segment to display on waveform in seconds (default 0.15)
Thaat Penalty Factor
Penalty (0–1) applied to HPCP energy at notes absent from a thaat (default 0.9)

Permanently delete all jobs with status "failed" and free up their disk space.
Resync Project Database
Scan the job storage folder and add any projects that exist on disk but are missing from the database. Run this if a project appears in the admin job list but not on the main project listing page.
